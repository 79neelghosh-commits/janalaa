JANALAA — Bengali Entertainment Website

Project structure
 index.html       Website content and page structure
 css/styles.css   Website styling and responsive layout
 js/app.js        Browser interactions
 images/          Poster image assets

OPEN LOCALLY
Double-click index.html, or run start-local-server.bat and open
http://localhost:8080.

PUBLISH ONLINE
Upload the complete janalaa-site folder to a static hosting provider such as
Netlify or Cloudflare Pages. Keep the css, js, and images folders together
with index.html.

This package is a static front-end website. It does not currently include a
server, database, accounts, or payment processing.
